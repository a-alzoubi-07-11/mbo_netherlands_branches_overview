# نظام الوكلاء بعد نقل الموقع

الموقع الأساسي ودليل التعليم الآن على
[a-alzoubi-07-11.github.io](https://a-alzoubi-07-11.github.io/).
ملفات الوكيلين وجدول الفحص اليومي مثبتة في مستودع هذا الرابط القصير.

هذا الفرع يضيف فقط `.github/workflows/site-agents.yml` إلى مستودع الرابط
الطويل: يعمل عند تحديث أي فرع فيه، ويستدعي الوكلاء من مستودع الموقع الرئيسي.
تبقى صفحة `index.html` المنشورة هنا صفحة تحويل؛ لا يستبدلها هذا الفرع.

يعرض كل تشغيل تقريرين تحت Actions → Artifacts. يتولى تشغيل `main` اليومي
في مستودع الرابط القصير فحص صفحات GitHub Pages العامة المكتشفة من حساب
`a-alzoubi-07-11` ومواقعها المنشورة.

إنشاء مستودع جديد لا ينسخ GitHub Actions إليه تلقائياً: لفحص فروعه عند
الدفع، انسخ ملف workflow المستدعي إلى المستودع الجديد. يبدأ الفحص اليومي
لصفحته العامة بعد تفعيل GitHub Pages واكتشافها.

ميزة اقتراحات AI تحتاج `AI_API_KEY` اختيارياً في Secrets على المستودع
الرئيسي. لا ينشر الوكلاء إصلاحات أو مقالات تلقائياً.
